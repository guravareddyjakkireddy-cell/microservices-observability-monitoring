# Microservices Observability Monitoring

## Overview
Enterprise-grade observability solution for Spring Boot microservices implementing centralized logging, monitoring, health checks, API performance tracking, and error monitoring using ELK Stack, Prometheus, and Grafana.

## Features
- Centralized Logging with ELK Stack
- Prometheus Metrics Collection
- Grafana Dashboards
- Spring Boot Actuator Health Checks
- API Response Time Monitoring
- Error Tracking and Alerting
- Docker-Based Deployment

## Technology Stack
- Java 17
- Spring Boot
- Prometheus
- Grafana
- Elasticsearch
- Logstash
- Kibana
- Docker
- Maven
